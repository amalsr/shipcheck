# ShipCheck

A small task manager built with React + TypeScript + Vite, used as a playground for
end-to-end testing with **Playwright** and a **CI/CD** pipeline with GitHub Actions.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173
